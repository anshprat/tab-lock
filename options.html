    Lock Behavior

    This is a browser-level deterrent, not a security boundary — anyone with access to your Chrome profile can disable this extension from chrome://extensions. There is no password recovery; if you forget it, remove the extension's data from chrome://extensions (or reinstall it) and set a new one.
